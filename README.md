# 뉴스 요약 챗봇 (CLI)

키워드를 입력하면 구글 뉴스에서 관련 뉴스를 최대 10개까지 가져와 간단히 요약해 주는 파이썬 기반 CLI 챗봇입니다.

## 1. 환경 설정

1. 파이썬 3.9 이상을 설치합니다.
2. 이 프로젝트 디렉터리로 이동합니다.

```bash
cd 222
```

3. 필요한 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

## 2. 실행 방법

```bash
python news_chatbot.py
```

이후 화면에 나오는 안내에 따라 키워드를 입력하면 됩니다.

## 3. 동작 방식 개요

- `https://news.google.com/rss/search` RSS 피드를 사용해 키워드 관련 뉴스를 가져옵니다.
- 최대 10개의 `item`을 가져와 제목, 링크, 날짜, 설명을 추출합니다.
- 설명(description)에 포함된 HTML 태그를 제거하고, 너무 길면 300자 정도로 잘라 간단한 요약 텍스트를 만듭니다.
- CLI 상에서 각 뉴스를 순서대로 출력합니다.

※ 실제 서비스/배포 시에는 구글 서비스 약관을 반드시 확인하고, 상용 목적이라면 공식 API 사용을 검토하는 것이 좋습니다.
